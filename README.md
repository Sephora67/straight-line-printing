# Straight Line Printing

Website source for straightlineprinting.ca, built with Lovable (TanStack Start + Lovable Cloud / Supabase + Stripe).

## Notes

- `.env` and secrets are not included in this repository.
- The database content (products, orders, customers) lives in Lovable Cloud and is exported separately via Cloud → Advanced settings → Export data.
- This is a snapshot export; continuous two-way sync can be enabled via Lovable's GitHub sync (Plus menu → GitHub → Connect project).
